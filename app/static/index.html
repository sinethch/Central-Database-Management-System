Restore Snapshot

Choose which saved snapshot to copy, where to restore it, and whether to create a database or write into an existing one.

Only databases with a completed snapshot can be used as a restore source. Registered PostgreSQL databases without a completed snapshot are shown as unavailable. Choose a registered database to narrow the snapshot list. This is the source; the destination is selected separately below.
This is a saved copy of the source database. The source is unchanged unless you explicitly choose it as the existing restore target.
ⓘ Before restoring, check the PostgreSQL major version on the snapshot source and target. Use the same major version for the most reliable restore; restoring a newer-version snapshot to an older server may fail because it does not support settings or features in the archive.
Only “Local or mounted repository” appears until this snapshot has a verified copy on a registered remote server. To add a remote option, register a server in Servers and copy this snapshot there. Remote copies can only restore into a new database.
Choose a registered PostgreSQL target. To restore into another existing database, choose “Write into an existing database” below; this list will show registered PostgreSQL databases you can select.
